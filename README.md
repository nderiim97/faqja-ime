# Faqja Ime Online

Kjo është faqja ime e thjeshtë e krijuar me Grok dhe e lidhur me GitHub.

## Si ta aktivizosh GitHub Pages

1. Shko te repository: https://github.com/nderiim97/faqja-ime
2. Kliko **Settings** (Cilësimet)
3. Në menunë e majtë, zgjidh **Pages**
4. Nën "Source", zgjidh **Deploy from a branch**
5. Branch: **main** dhe folder: **/ (root)**
6. Kliko **Save**

Pas disa minutash, faqja do të jetë e disponueshme në:

**https://nderiim97.github.io/faqja-ime/**

## Ndryshimi i faqes

Mund të editosh `index.html` direkt në GitHub ose lokalisht dhe të bësh push.
